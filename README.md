# Wanted: Dead — бот для рамен-мини-игры

Бот для PS5, который сам играет ритм-мини-игру с раменом в **Wanted: Dead** и берёт
трофей **«Ramen World Legend»** — 250 попаданий подряд без единого промаха.
Этим ботом взято комбо **268** (с запасом 18).

Заодно, без отдельного режима, берётся **«I Got Room»** (съесть больше 5 порций рамена
подряд) — бот просто бесконечно переигрывает песни, нажимая Retry на экране результатов.

- Зрение, без звука: всё считается по картинке из потока Remote Play.
- Ничего не инжектится в игру — бот работает как виртуальный геймпад консоли.
- Работает на любом ПК с Python 3.10+ в той же локальной сети, что и PS5.

---

## 1. Что нужно

| Требование | Подробности |
|---|---|
| PS5 | Remote Play включён: **Настройки → Система → Remote Play → Включить** |
| PSN | аккаунт, привязанный к консоли (тот же, что в PSN на PS5) |
| ПК | Windows 10/11, Python 3.10 или новее, 1 свободное ядро CPU |
| Сеть | ПК и PS5 в одной локальной сети, желательно по кабелю |
| Сама игра | Wanted: Dead, мини-игра с раменом открыта вручную (бот меню не ходит) |

Важно: PS5 должна быть **не занята другой сессией Remote Play** (второй ноутбук,
телефон, PS Remote Play на этом же ПК) — иначе подключение отвалится.

---

## 2. Установка

### Вариант «в один клик»

1. Поставь [Python 3.10+](https://www.python.org/downloads/), при установке отметь
   **Add Python to PATH**.
2. Запусти `setup.bat` — он создаст окружение `.venv` и поставит зависимости.

### Вручную

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

`rapidocr-onnxruntime` не обязателен: без него бот играет так же, просто не пишет в лог
результаты песни (Perfect/Great/Miss/Max Combo/Score).

---

## 3. Первый запуск: привязка консоли

```bat
:: найти консоль в сети
.venv\Scripts\python.exe ramen_bot.py --discover
```

Покажет IP и тип найденных консолей. Дальше привязка:

```bat
.venv\Scripts\python.exe ramen_bot.py --register 192.168.1.50
```

Скрипт попросит ссылку/код PSN и покажет **PIN**. На PS5: **Настройки → Система →
Remote Play → Связать устройство** — введи PIN. После этого привязка запомнится,
повторять не нужно.

---

## 4. Запуск бота

```bat
run.bat 192.168.1.50
```

или напрямую:

```bat
.venv\Scripts\python.exe ramen_bot.py --run 192.168.1.50 --trophy
```

Откроется окно с живым видео консоли. Порядок действий:

1. Зайди в игру и вручную открой мини-игру с раменом (бот меню не навигирует).
2. **Нажми `C`** и мышью выдели прямоугольник вокруг полосы с нотами — так задаётся
   рабочая зона (ROI).
3. Внутри зоны **кликни по линии попадания** — по спиральке, куда приезжают ноты.
   Для каждого ряда отдельно (один клик на ряд). Разметка запоминается в
   `%USERPROFILE%\Videos\WantedDeadRamen\roi_state.json` и подхватывается в следующий раз.
4. Нажми `SPACE` — автонажатия включены. Дальше бот играет сам.

Горячие клавиши в окне:

| Клавиша | Что делает |
|---|---|
| `SPACE` | включить / выключить автонажатия |
| `C` | заново разметить поле и линии |
| `[` и `]` | сдвинуть опережение (lead) на 10 мс: `]` если жмёт рано, `[` если поздно |
| `x` `o` `q` `t` `l` `b` | ручные кнопки: крест, круг, квадрат, треугольник, L2, R2 |
| `P` | OPTIONS |
| `ESC` | выход |

## 5. Параметры командной строки

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--run IP` | — | подключиться к консоли и играть |
| `--discover` | — | найти консоли в сети |
| `--register IP` | — | привязать консоль (PSN + PIN) |
| `--lead-ms N` | `51` | опережение нажатия в мс. Больше — раньше нажатие. Подбирается под свою сеть |
| `--trophy` | выкл | трофейный режим: сам различает экраны, читает результаты, жмёт Retry |
| `--auto-retry-delay S` | `8` | сколько ждать на экране результатов перед Retry |
| `--skip-first N` | `20` | не нажимать первые N нот песни (рецепт из сообщества для этого трофея) |
| `--song-end-wait S` | `12` | сколько секунд без нот считать концом песни |
| `--auto-menu` | выкл | если в интро нет нот, прокликивать X каждые 4 с |

Логика подбора `--lead-ms`: играй и смотри на результат. Промахи «рано/поздно» по
краям — крути опережение на ±10 мс, пока нажатия не встанут по линии. Для проводной
сети и PS5 рядом с роутером обычно 45–60 мс.

---

## 6. Где лежат данные

Бот пишет в `%USERPROFILE%\Videos\WantedDeadRamen\`:

| Файл | Что внутри |
|---|---|
| `roi_state.json` | разметка поля и линий попадания (создаётся, когда ты размечаешь через `C`) |
| `bot.log` | журнал: подключения, результаты каждой песни, ошибки |

Эталонная разметка для 720p лежит в репозитории (`roi_state.json`) и используется, если
своей ещё нет. Если поле у тебя на экране в другом месте — просто разметь заново через `C`.

## 7. Как это работает (коротко)

1. `pyremoteplay` отдаёт кадры Remote Play (720p, 60 fps, качество `very_high`).
2. Внутри ROI нота ищется по кружкам (Hough) и ярким пятнам, значок распознаётся
   сопоставлением с шаблонами из `ramen_templates.npz`.
3. Нота ведётся «треком» от правого края до линии попадания, чтобы нажатие уходило
   ровно в момент, а не «когда заметили».
4. Удержание — бирюзовая полоса: нажатие на левом конце (значок головы), отпускание на
   правом. Ноты-значки на концах полосы убираются из обычной логики, чтобы не нажимать
   их второй раз.
5. В трофейном режиме бот различает экраны по яркости: GAMEPLAY → RESULTS (тёмный) →
   Retry. На экране результатов читает статистику (если есть `rapidocr`) и жмёт X.

Ключевые настройки подобраны замерами на живых прогонах, они в начале `ramen_bot.py`
(`lead`, допуски рядов, окно отсева повторов, пороги уверенности распознавания).

## 8. Частые проблемы

| Симптом | Что делать |
|---|---|
| «PS5 не отвечает по Remote Play» | проверь IP, включён ли Remote Play, не занята ли консоль другой сессией |
| «Нет связанного профиля» | выполни `--register` |
| Окно есть, но бот не нажимает | разметка не сделана или линии не выставлены: нажми `C`, выдели поле и кликни по спиралькам |
| Нажимает мимо (рано/поздно) | подкрути `--lead-ms` или клавишами `[` / `]` |
| Сначала всё хорошо, через 10–15 минут начинает мазать | цикл обработки кадра деградирует в долгой сессии: перезапусти бота |
| Видео дёргается | закрой лишние программы, PS5 лучше по кабелю; качество потока снижать не надо, от него зависит распознавание значков |
| Трофей не падает, хотя комбо большое | трофею нужно **250 подряд**; смотри `Miss` в `bot.log` — каждая пропущенная нота обнуляет серию |

## 9. Ограничения и честные предупреждения

- Бот **не проходит меню и не выбирает песни** — до мини-игры дойди руками.
- Бот видит только картинку: со звуком он не работает и не может.
- Автоматизация трофеев может нарушать пользовательское соглашение PSN. Игра
  одиночная, но решение использовать бота — на твой риск.
- Точность зависит от качества потока: при сильном сжатии значки читаются хуже.
  Помогает проводная сеть и `quality="very_high"` (уже выставлено в коде).

## 11. English (short)

A PS5 bot for the ramen rhythm minigame in **Wanted: Dead**. It uses `pyremoteplay` to
read the Remote Play stream, detects notes and their glyphs with OpenCV template
matching, and presses the right buttons with the right lead time. With `--trophy` it
detects the results screen, logs the stats and presses Retry automatically, farming
servings until the **Ramen World Legend** trophy (250 hits in a row) pops.

```bat
python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt
python ramen_bot.py --discover
python ramen_bot.py --register <PS5_IP>
python ramen_bot.py --run <PS5_IP> --trophy
```

Press `C` in the video window to outline the note lane and click each hit line, then
`SPACE` to start. Tune timing with `--lead-ms` (default 51 ms). Vision only, no audio.
